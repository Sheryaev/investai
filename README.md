# Invest AI

Локальное Windows-приложение для анализа портфеля Т-Инвестиций с графиками, операциями и чатом с локально установленными ИИ-агентами.

## Возможности

- стоимость портфеля, прибыль и динамика стоимости;
- позиции с поиском, фильтрами и сортировкой;
- распределение по валютам и отраслям, показатели концентрации;
- свечной график инструмента, объём и связанные операции;
- история операций с фильтрами по счёту, типу и периоду;
- локальные снимки и история чатов в SQLite;
- демо-режим без токена брокера;
- чат с явно выбранным Codex, Kimi или Claude CLI.

## Требования

Для разработки и сборки:

- Windows 10/11 x64;
- Node.js 22.12 или новее;
- npm.

Для работы с брокером нужен токен Т-Инвестиций **только с правами чтения**. Приложение не размещает заявки и не выполняет сделки.

Для ИИ-чата нужен хотя бы один установленный и авторизованный CLI:

```bash
codex login
kimi login
claude
```

Claude авторизуется в интерактивном терминале. Команды входа также доступны в настройках приложения. API-ключи ИИ в Invest AI не нужны: используется авторизация выбранной локальной CLI-программы.

## Запуск в режиме разработки

```bash
npm install
npm run dev
```

При первом запуске доступен демо-режим. Для реальных данных откройте «Настройки», сохраните read-only токен, переключитесь на данные брокера и выберите нужные счета.

## ИИ-чат

1. Установите и авторизуйте нужный CLI.
2. Откройте «Настройки» и проверьте его статус.
3. В разделе «ИИ-чат» выберите агента и отправьте вопрос.

Портфельный контекст автоматически передаётся только выбранному CLI при отправке сообщения. Идентификаторы и пользовательские названия счетов заменяются обезличенными обозначениями. Скрытого переключения на другого агента нет. Ответ можно остановить или повторить.

## Тесты и проверки

```bash
npm run test:unit
npm run test:e2e
npm run build
```

E2E-тест запускает настоящее Electron-окно с временным изолированным профилем.

## Сборка Windows-установщика

```bash
npm run dist:win
```

Результаты:

- `release/Invest-AI-Setup-0.1.0.exe` — NSIS-установщик;
- `release/win-unpacked/Invest AI.exe` — переносимая упакованная версия для smoke-проверки.

Smoke-проверка упакованной версии с временным профилем:

```bash
node scripts/smoke-packaged.mjs
```

Сборка без сертификата подписи не имеет цифровой подписи, поэтому Windows SmartScreen может показать предупреждение.

## Хранение и безопасность

- Токен брокера шифруется через Electron `safeStorage` и доступен только главному процессу.
- Данные приложения и SQLite-база хранятся в локальном профиле пользователя.
- CLI запускаются без shell, в пустой рабочей папке, с ограничением времени и возможностью отмены.
- Журналы не содержат токены, prompt и содержимое переписки.

## Проверка в текущем окружении

Unit-тесты, production-сборка и Electron E2E проверяются локально. Реальные запросы к брокеру и платные запросы к Codex, Kimi и Claude в среде разработки не выполнялись; эти интеграции необходимо проверить с вашими авторизованными программами и read-only токеном.
